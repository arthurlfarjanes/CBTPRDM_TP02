## ✨ Funcionalidades

- [x] **Visualização de Tarefas:** Lista inicial exibindo título e uma breve descrição de cada item.
- [x] **Navegação Hierárquica:** Acesso a uma página de detalhes completa (com data de criação e prioridade).
- [x] **Criação via Modal:** Adição de novas tarefas através de uma janela sobreposta.
- [x] **Edição via Modal:** Alteração dinâmica dos dados da tarefa selecionada.
- [x] **Exclusão Segura:** Remoção de tarefas protegida por um diálogo de confirmação (Alert).

---

## 🛠️ Tecnologias Utilizadas

- **Framework:** .NET MAUI
- **Linguagem:** C#
- **Interface:** XAML (Data Binding, INotifyPropertyChanged)
- **Componentes:** CollectionView, NavigationPage, Modals e DisplayAlert.

---

## 🚀 Como Executar

1. Clone este repositório em sua máquina local.
2. Abra a solução no **Visual Studio 2022** (certifique-se de ter a carga de trabalho de desenvolvimento com .NET MAUI instalada).
3. Selecione o dispositivo alvo no topo (Ex: *Windows Machine* ou um *Emulador Android*).
4. Clique em **Executar (F5)**.
